## 5. Image plan

### Required project images
Use real screenshots wherever possible:
- Support Copilot interface
- Insight Pipeline workflow
- Decision Dashboard interface

### Decorative images
Keep decorative imagery abstract and consistent. Avoid generic AI robot imagery because it can make the portfolio feel interchangeable.

### Rejection note
Rejected generic AI/robot imagery because it communicates “AI” immediately but does not communicate the actual project or demonstrate the creator's work. The portfolio should use its visual space to provide evidence rather than decoration.
