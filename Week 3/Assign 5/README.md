# Week 3 AI Fluency Portfolio

A complete responsive portfolio starter created for the Week 3 assignment.

## Run locally

No build tools are required.

1. Extract the ZIP.
2. Open `index.html` in a browser.

For the best development experience, use VS Code + Live Server.

## Files

- `index.html` — portfolio structure and content
- `style.css` — responsive visual design and identity kit
- `script.js` — mobile navigation interaction
- `week-03-assignment.md` — Week 3 submission content
- `assets/` — place real project screenshots/assets here

## Customize before submitting

Replace:
- Alex Morgan with your real name
- `hello@example.com` with your email
- GitHub/LinkedIn placeholder links
- The three sample projects with your real projects
- Project screenshots with real screenshots
- Placeholder results with real evidence

The visual identity is intentionally minimal so the work remains the focus.
